# 装修器

哈喽！你说的应该是 Python 中的 **装饰器（Decorator）**（“装修器”这个词听起来像是给房子装修，不过用来形容给函数“精装修”也挺形象的！）。

  

Python 装饰器是 Python 中非常强大且优雅的一个特性。简单来说，装饰器本质上是一个**闭包函数**，它可以在**不修改原函数代码**的前提下，给原函数增加额外的功能（比如日志记录、权限校验、性能测试、缓存等）。

  

### 一、 核心概念：什么是装饰器？

在 Python 中，**函数是一等公民**（First-class citizen），这意味着函数可以像普通变量一样被传递、赋值和作为返回值。

  

装饰器的基本思路就是：

  

> **输入一个函数 $\rightarrow$ 包装/增强它 $\rightarrow$ 返回一个新的函数**
> 
>   

### 二、 一个最简单的装饰器例子

假设我们想在某个函数执行前后打印一些日志，但又不想修改这个函数本身的代码，我们可以写一个装饰器：

  

Python

```
# 1. 定义装饰器函数
def log_decorator(func):
    def wrapper():
        print("--- 函数开始执行 ---")
        func()  # 执行原函数
        print("--- 函数执行结束 ---")
    return wrapper

# 2. 使用 @ 语法糖应用装饰器
@log_decorator
def say_hello():
    print("Hello, Python!")

# 3. 调用函数
say_hello()
```

**输出结果：**

  

Plaintext

```
--- 函数开始执行 ---
Hello, Python!
--- 函数执行结束 ---
```

> **提示**：`@log_decorator` 语法糖本质上等价于：`say_hello = log_decorator(say_hello)`。
> 
>   

### 三、 进阶：处理带参数的函数

上面的例子中，`say_hello` 没有参数。如果被装饰的函数需要接收参数，我们的装饰器内部的 `wrapper` 函数就需要使用 `*args` 和 `**kwargs` 来接收任意参数：

  

Python

```
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print(f"正在调用函数: {func.__name__}")
        result = func(*args, **kwargs)  # 接收原函数的返回值
        print("调用完成！")
        return result
    return wrapper

@my_decorator
def add(a, b):
    return a + b

sum_result = add(3, 5)
print(f"计算结果: {sum_result}")
```

### 四、 常见应用场景

在实际开发中，装饰器常用于以下场景：

  

1. **日志记录（Logging）**：自动记录函数的调用时间、参数和返回值。
    
      
    
2. **权限校验（Authorization）**：在 Web 框架（如 Django、Flask）中，检查用户是否登录或有权限访问某个路由。
    
      
    
3. **性能测试（Timing）**：计算函数的运行耗时。
    
      
    
4. **缓存（Caching）**：保存函数的计算结果，避免重复计算（如标准库中的 `@functools.lru_cache`）。
    
      
    

#### 示例：计算函数耗时的装饰器

Python

```
import time
import functools

def time_it(func):
    @functools.wraps(func)  # 保留原函数的元信息（如函数名、docstring）
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        print(f"函数 {func.__name__} 耗时: {end_time - start_time:.4f} 秒")
        return result
    return wrapper

@time_it
def heavy_task():
    time.sleep(1)
    print("任务执行完毕")

heavy_task()
```
